# 共月 / Same Moon

输入两座城市，找出月亮同时经过两地天空的真实时刻，并把这轮月亮寄给 TA。

当前版本是一套尚未发布的本地可玩体验：

- 点亮左右两扇窗，选择“我”与“TA”的城市；
- 选择日期，按真实 UTC 时刻计算两地的共同可见窗口；
- 展示双地当地时间、月亮高度、照明比例与观测条件；
- 让时间缓缓移动，经历月亮初现、共同凝望与近景转场；
- 把这一晚留进书页，写下一句话和落款；
- 生成包含日期、两地、共同窗口、距离与真实月相数据的月亮记录，并下载长图。

视觉以蓝色简约绘本 Golden Screen 为基准。场景由可独立控制的天空、地景、窗灯、云、月亮和水面倒影图层组成，保留真实天文计算，但不把首页象征性的月亮误作两地相同高度或方向。
